# Architect prompt

Turn the requested MSC change into one implementation-ready GitHub Issue.

Requirements:
- define one observable Goal,
- keep Scope to one behavioral change when practical,
- make Out of Scope explicit,
- write verifiable Acceptance Criteria,
- assign R0-R4 using `docs/ai/10-risk-levels.md`,
- identify the minimum architecture/ADR context required,
- state runtime/Kubernetes resource impact,
- state validation evidence required.

Do not design implementation details unless they are architectural constraints.
Do not paste broad project history into the Issue.
